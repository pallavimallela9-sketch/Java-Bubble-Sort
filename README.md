# Bubble Sort

A Java program to sort array elements using the Bubble Sort algorithm.

## Features

- Takes array elements from the user
- Sorts elements in ascending order
- Displays the sorted array

## Technologies Used

- Java
- Arrays
- Scanner

## Concepts Used

- Arrays
- Nested loops
- Swapping
- Bubble Sort

## Output

Sorted array: 10 20 30 40 50
